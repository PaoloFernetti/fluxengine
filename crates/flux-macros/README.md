# flux-macros

Служебный proc-macro пакет: дерайвы и атрибуты для схем компонентов.
Не единица канона (ADR-0028): не крейт движка и не инструмент.

Канон: [`docs/canon.md`](../../docs/canon.md). Формат схемы и дельты: ADR-0030.

## Ответственность одной строкой

`#[derive(Reflect)]`, `#[save]`, `#[replicated]`, `#[reflect(...)]`,
`#[field(uuid = "...")]` — генерация метаданных `ComponentSchema` без
бизнес-логики.

## Правила

- Зависимости только `syn`/`quote`/`proc-macro2`; никаких крейтов движка —
  направление строго одно (циклы невозможны).
- Дерайв «глупый»: собирает метаданные, не обращается к рантайму.
- Ошибки атрибутов — ошибки компиляции (`trybuild` в тестах).
- Генерируемый код — публичный ABI контента: меняется только через ADR.
