# FluxEngine — Юридический минимум

## 1. Лицензия движка

- FluxEngine распространяется под **MIT** (см. [LICENSE](../LICENSE),
  Copyright (c) 2026 Paolo Fernetti).
- MIT выбран для v1: разрешает коммерческое использование, модификацию и
  проприетарные игры на движке. Ограничение ответственности — стандартное.
- Смена лицензии — только через ADR (затрагивает всех пользователей движка).

## 2. Лицензии зависимостей

Правило: в репозиторий попадают только зависимости с разрешительными
лицензиями. Проверка — автоматическая в CI (`cargo-deny`).

Allowlist (стартовый):
- MIT, Apache-2.0, BSD-2/3-Clause, ISC, Zlib, Unlicense, MPL-2.0
  (MPL — file-level copyleft, допустим без влияния на код движка).

## 3. Данные пользователей

- Игра/движок по умолчанию **не собирает** персональные данные.
- Crash-дампы: сохраняются локально; отправка (телеметрия) — только
  opt-in с явным согласием, с уведомлением о содержимом.
- Метрики производительности (FPS, frametime) — локальные; агрегированная
  телеметрия (если появится) — анонимная, без идентификаторов.
- Сетевой слой: персональные данные не хранятся движком; ответственность
  за данные игроков — у игры (политика конфиденциальности проекта).
- GDPR-минимум (если появится онлайн-сервис): право на удаление, сроки
  хранения, перечень данных — фиксируются ADR до запуска сервиса.

## 4. Контент и моддинг

- Движок не накладывает лицензию на контент игр (ассеты — собственность
  проекта/авторов).
- Моддинг (отложен, ADR-0025): при появлении — политика в отношении
  пользовательского контента (запрещённый контент, DMCA-процедура,
  ответственность автора мода) фиксируется отдельным документом до релиза
  моддинг-инфраструктуры.
- Шрифты: в .fpf допускаются только шрифты с лицензией, разрешающей
  встраивание (OFL/Apache); проверка — при импорте ассета в flux-assetc.

## 5. Атрибуции

- MIT-код движка: сохранение copyright-уведомлений обязательно при
  распространении (включая игры на движке — в «лицензиях» игры).
- Сторонние компоненты: файл THIRD_PARTY_NOTICES (генерируется
  `cargo-deny`/`cargo-about` в релизном пайплайне).

## 6. Секреты и распространение

- Ключи подписи паков/релизов — только в секретах CI; не в репозитории,
  не в артефактах без подписи.
- Подпись модов (задел ADR-0025): слот в манифесте зарезервирован;
  инфраструктура — отдельное решение.
