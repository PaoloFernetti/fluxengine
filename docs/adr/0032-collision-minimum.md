# 0032. Collision-минимум: тайлы, капсула/луч, свипы, детерминированный обход

- Статус: Accepted
- Дата: 2026-11-13
- Затрагивает: flux-physics (collision), flux-math, flux-engine (PIE)
- Связано: ADR-0003 (своя физика f64), ADR-0024 (KCC-минимум), ADR-0007
  (детерминизм), ADR-0008 (координаты)

## Контекст

Для PIE и M3 нужна ходьба: капсула не проходит сквозь стены, стоит на
полу, поднимается по ступеням. Полное физическое ядро (broadphase,
narrowphase, solver, CCD, joints) — этап 6 (ADR-0024). На этапе 3 нужен
минимальный collision-слой: запросы пересечений/свипов без solver, с
детерминированным результатом на одной платформе.

## Варианты

1. **Rapier.** Плюс: готово. Минус: отброшен ADR-0003 (f64, детерминизм,
   масштаб мира, контроль).
2. **Свой BVH + narrowphase.** Плюс: масштабируется. Минус: для тестовой
   сцены этапа 3 — преждевременная сложность; solver всё равно этап 6.
3. **Тайловый grid + свипы капсулы/луча.** Плюс: простой, детерминированный,
   достаточен для KCC-минимума. Минус: не общая геометрия; расширяется на
   этапе 6.

## Решение

Выбран вариант 3.

### Геометрия и запросы

```rust
pub struct TileGrid { /* AABB-ячейки, solid-флаг, детерминированный порядок */ }
pub struct Capsule { pub radius: f64, pub half_height: f64 }
pub struct Ray { pub origin: DVec3, pub direction: DVec3, pub max_distance: f64 }

pub struct Contact {
    pub time: f64,          // 0..1 вдоль свипа
    pub normal: DVec3,
    pub point: DVec3,
}

impl TileGrid {
    pub fn from_rows(rows: &[&str]) -> Self;
    pub fn sweep_capsule(&self, capsule: &Capsule, from: DVec3, to: DVec3) -> Option<Contact>;
    pub fn raycast(&self, ray: &Ray) -> Option<Contact>;
}
```

- **Без solver.** Запросы возвращают контакт; коррекция и решение о
  движении — в KCC (ADR-0024).
- **Детерминированный обход.** Тайлы перебираются по `(y, x)` индексам;
  первый контакт при равном `time` — с меньшим индексом. Никаких
  `HashMap`-итераций.
- **f64.** Все вычисления — `f64`; канон `WorldPos` конвертируется на
  границе тика (ADR-0008).
- **Капсула** — вертикальная; наклонные поверхности — через нормаль
  контакта и `slope_limit` KCC.

### Границы

- Collision-минимум не знает про ECS; системы KCC вызывают его.
- `TileGrid` — тестовая/простая геометрия; general mesh — этап 6.
- Никакого CCD: свипы капсулы на фиксированном шаге; tunnelling исключён
  скоростями KCC-минимума.

## Следствия

Плюсы: детерминизм и простота; быстрые тесты без GPU/окон; KCC получает
стабильный контракт.

Минусы/риски: тайловый grid не покрывает произвольную геометрию; при
появлении полноценного ядра контракт `sweep_capsule`/`raycast` сохраняется,
меняется реализация.

Заделы: broadphase/BVH и solver — этап 6; world partition × navmesh — этап 4–5;
сетевой rewind использует те же чистые запросы.
